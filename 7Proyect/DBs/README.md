# Proyecto CRUD con Python, Flask y SQLite

Aplicación web que permite insertar, consultar, modificar y borrar registros en una base de datos relacional (SQLite).

## Uso de Inteligencia Artificial
Se utilizó asistencia de Inteligencia Artificial para estructurar las rutas CRUD en Flask, diseñar las consultas SQL parametrizadas y maquetar el formulario responsivo con Bootstrap.

## Instalación y ejecución
1. Instalar dependencias:
`npm init -y
npm install express sqlite3 ejs
`
2. También puedes usar: `npm install`
3. Ejecutar: `node server.js`
4. Abrir en el navegador: `http://localhost:3000`
